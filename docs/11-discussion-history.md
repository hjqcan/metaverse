# 讨论沿革与成果覆盖

首次整理：2026-10-25；更新：2026-10-26（Asia/Shanghai）。

本文件保留本轮讨论的意图演进、重要澄清及设计成果位置。它不是逐字聊天导出；重复论述已合并，最后明确的用户意图优先。未把与项目无关的个人资料纳入仓库。

## 1. 起点：用系统科学与 AI 建设长期世界

用户提出以系统论、控制论、信息论、高等数学等为基础，结合 AI、视觉、LLM、机器学习、强化学习、RSI、神经网络、卷积、贝叶斯、傅里叶、滤波、梯度下降、拟合、图论和概率论等知识，从零开始构建元宇宙游戏。

核心期望包括：底层可以逐步叠加、不急于完成；玩家共建；物品不能随意增加、制造需要消耗物质；建立逐渐轻度膨胀的经济；区块链可以研究。长期愿景是让人类逐渐把活动迁入虚拟世界。

讨论由此展开了资源账、制造规则、蓝图与实例、货币与物价、开放创造、治理和研发方法等主题。早期提出工业聚落与机器人作为切入场景，属于助手建议。

## 2. 澄清世界形态：空间、内容与规律都可增长

用户进一步描述：最初可以只有一小片陆地，随后通过玩家建设出现海洋、星空、外星球，以及天堂和地下世界；类似 Minecraft 或 Roblox 所体现的可创造性，最初只有少量基本规则，很多内容由玩家构建，基本规则也继续增加。

据此，产品方向扩展为持续生长的世界，而不是预先限定为工业聚落。讨论提出元规则、具体规则、内容分层，以及地区规则、版本、跨区转换等候选设计。

尚未确定：普通玩家是否能够直接实现和发布新规律，以及全局与局部的治理权限。

## 3. 澄清参与方式：人类和 Agent 都可入驻

用户明确指出：这个世界供人类和 Agent 入驻，不需要继续强调“人类为什么重要”；人类可以通过创造获得价值与满足，也可以不工作，只享受丰富的世界。

因此，文档不把人类劳动、生产效率或必须赚钱作为入驻资格。Agent 也不被预设为只能承担重复劳动。资源与预算设计需要支持多种参与方式。

同一轮中，用户提出 Agent 分工调研、构建、入驻测试，使软件研发能够形成反馈闭环。

## 4. 关键澄清：主研发团队在世界外

助手曾额外讨论居民在世界内发现需求、主动研究和推动规则演化。用户认为这是有趣补充，但进一步明确了原意：

> 可以有一批 Agent 像本次讨论一样探讨、调研并得出方案，其他 Agent 构建虚拟元宇宙，再由另一批 Agent 入驻活动和测试。构建与测试的结果反馈给做调研的 Agent，迭代更好的方案。

这是对用户最后澄清的整理转述。其主线为：

1. 外部调研与方案设计。
2. 外部软件和内容构建。
3. 候选世界内部活动与测试。
4. 构建可行性、实际运行后果共同回流外部研究。

世界内自主提案保留为可选来源，不作为当前闭环的必要条件。没有要求研究 Agent 必须成为世界里的居民。

## 6. 新增方向：文明随玩家进度发展，2026-10-26

用户进一步明确，虚拟元宇宙中的文明会发展，速度取决于玩家的进度。最早进入的玩家可能是散落的原始居民，需要砍木、求生，逐渐形成部落；后入玩家可能面对已有自动化、摩天大楼，甚至星际旅行，因而不再重复早期的全部活动。

这次补充明确了共同世界的历史积累与跨批次参与体验，新增确认记录为 C13—C15。它延续人类与 Agent 共居、可以只游玩、资源有来源以及外部研发闭环等既有方向。

本轮研究核对 One Hour One Life 的跨世代继承、Eco 的设备升级、Factorio 的研究与蓝图、Screeps 的持续运行，以及 Factorio Learning Environment 的 Agent 评测。机制依据和适用边界见 R14—R18。

据此提出的能力分布、地区差异、当代入驻、知识与设施分离、维护及服务模型，均作为建议记录。用户没有在本轮确定公共福利制度、私有或公开知识政策、固定时代时长、文明衰退或清档机制。

路线建议新增 `EXP-0002`“从手工建造到共享工坊”，直接检验同一世界中前人建设能否被后入者使用。原 `EXP-0001` 两地通行保留为可选基础机制实验；这是候选方案的演进，两个实验均未实施。

用户本轮明确授权分析、研究、完善文档并推送 GitHub。本轮交付继续属于设计与研究成果，不代表已经构建游戏或运行文明实验。

## 7. 新增约束：先发适度，不得垄断，2026-10-26

用户接着明确：先进来的人主要体验早期内容，并因游戏时间较长获得适度先发优势；不能优势过大，更不能形成垄断优势，否则会损害经济。分别记录为 C16、C17。

据此，将此前“后来者有发展空间”的建议加强为明确目标，并区分累积能力差距与关键入口封锁。后续方案要同时检查新人使用当代服务、独立创造和建立项目的真实路径。单纯显示访问限制、保证账本正确，或仅观察店铺数量，都不足以证明满足要求。

具体成长曲线、公共供给、稀缺经营权、技术许可和控制关系识别，继续作为待决机制；本轮未确定税制、财富上限、强制公开全部作品或清除既有资产。研究只借鉴官方游戏资料中的成长与共同参与思路，不将“任何集中都立即崩盘”作为已验证规律。

本轮新增先发与进入专题，联动更新相关文档，并为共享工坊实验补充拒绝服务、关联控制、长期差距和独立创造场景。没有运行游戏实验。
