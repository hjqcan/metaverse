# 先发优势与后来者机会：有积累，不封锁入口

日期：2026-10-26（Asia/Shanghai）。

状态：用户已确认先发优势应适度、不得形成垄断优势；本文具体制度、指标与压力场景是设计建议，尚未实施或验证。

关联：[文明演进](12-civilization-evolution.md)、[经济与资源](02-economy-and-resources.md)、[人类与 Agent 参与](03-human-and-agent-participation.md)、[决定记录](09-decisions-and-open-questions.md)。

## 1. 本轮确认的约束

用户明确：先进来的人主要体验早期内容，并获得适度的先发与游戏时长优势，不能因为早到而形成过大优势或垄断优势。该要求分别记录为 C16、C17。

这里包含两项需要同时验证的目标：一是先发产生的数值、资本与行动能力差距不能无限扩大；二是先行者不能依靠控制关键条件，让后来者必须依附其许可才能参与、建设或竞争。仅限制市场份额，不能保证第一项；仅限制角色等级，也不能保证第二项。

这不承诺所有人的财富、操作水平和创作结果一样。系统应保留历史、作品与合理回报，并限制这些积累转化为不可绕开的排他权。数值边界、资源制度和处置方式仍需实验确定。

用户指出其经济风险。本文将它作为设计预防目标，不把“出现垄断就立即崩盘”写成已证实的普遍规律。在本项目中，尤其需要检查交易仍在发生、但新人只能支付进入费用且无法继续创造的情形。

## 2. 分开历史价值、有限效用和排他权

| 积累类型 | 可以研究保留的价值 | 要约束的转化方式 |
|---|---|---|
| 亲历与历史 | 开荒经历、建设记录、纪念、故事 | 注册日期直接授予永久高倍率产出或规则否决权 |
| 作品与署名 | 故居、原创艺术、建筑、可追溯贡献 | 作品占据全体居民必须经过的唯一入口 |
| 经验与熟练 | 更熟悉系统、更多策略与操作经验 | 用无限叠加属性使后来者失去有效参与能力 |
| 工具与经营 | 实际建设、维护和服务带来的适度收益 | 资本反复购买排他条件，使后来者无法替代或竞争 |
| 声誉与组织 | 自愿形成的信任、社群和合作 | 将声誉或早期财富自动兑换为不可撤销的公共权力 |

独一无二的历史建筑或艺术品，不应仅因“只有一份”就被删除或强制复制。关键在于它是否控制基础参与和实际发展所必需的条件。收藏市场的高标价，也不等于世界居民的基本能力已经提高。

经验和关系不可能靠规则完全抹平；但其在世界中的资源使用、设施控制、交易和治理行为仍需要经过共同规则。把收益改名为“文化价值”，也不能豁免对实际排他效果的检查。

## 3. 成长可以更多体现为选择和表达

建议让较长游戏时间主要积累作品、历史、策略理解、组织经验和多种可选玩法；对可以直接支配他人的生产倍率、资源准入、行动吞吐等优势，研究可追赶的成长曲线与明确边界。

一种候选设计是：当代基础操作能力和工具比较容易取得，专业深度需要投入，而长期成长主要打开更多路线与表达方式。具体能力仍可有材料与设备门槛；不能仅改成横向选项，就声称市场竞争一定公平。

Guild Wars 2 的官方 Mastery 介绍展示了以新增交互与探索能力承接成长的思路；它仍包含能力和奖励，不能据此宣称老玩家没有任何优势。[R19](10-references.md#r19) Sea of Thieves 的早期官方介绍则把声誉、称号、外观和可共享任务纳入进度设计；这支持研究多样回报，不证明生产经济中的垄断问题已经解决。[R20](10-references.md#r20)

如果前沿技术不断提高社会能力，可以通过知识传播、共享设备与公共服务降低后来者取得当代基础能力的成本。传播范围和预算需要明确，也不能靠持续报废所有旧作品迫使老玩家重练。

## 4. 检查会成为必经入口的资源与权利

以下是候选机制，不是已经选定的经济制度。公共与私有供给可以组合，具体比例待定。

| 潜在封锁点 | 建议研究的机制 | 必须保留的成本与边界 |
|---|---|---|
| 普通土地与创作空间 | 持续提供可用的普通空间，保留公共通道；热点经营权与居民作品分开 | 新空间仍有服务器、建设和资源来源约束；无需复制同一黄金地段 |
| 基础材料与能源 | 多种来源、替代工艺、可进入的新供应路径和有来源的公共储备 | 扩张必须登记资源来源；不能以反垄断名义无限生成材料 |
| 生产设施 | 可租用或共享的基础设备，允许独立建设竞争设施，兼容必要接口 | 新设施仍需材料、运行投入和维护；不能保证所有经营者盈利 |
| 运输和关键通道 | 公共通行规则、替代路线；公共特许经营可附可验证的服务条件 | 成本、容量、履约和退出安排事先明确 |
| 基础知识与工艺 | 公共基础方法、替代实现、可选择的许可或有预算的公开采购 | 不默认没收所有私人设计；独立实现与内容复制权限分开 |
| 市场和发现入口 | 可获得的价格与商品信息、可替代的交易渠道、避免永久独占展示资格 | 信息可见性遵守权限；早期成交额不直接变成永久曝光特权 |
| 货币与治理 | 不因注册早或财富多自动获得永久发行权、不可撤销治理权或竞争者否决权 | 治理方式未选定；简单改成账号一票也存在分身问题 |
| Agent 与现实算力 | 记录控制关系、总预算及合法执行容量，检查补贴与分身 | 合并预算只能约束已知归属，不能假定系统已能识别所有共同控制者 |

“有第二家店”并不足够。如果两家店共用同一个被封锁的电网、仓库、运输线或许可源，仍可能没有实际替代。测试应覆盖整个依赖关系和特定居民所在的地区。

早期刚建成第一家工坊，也不因暂时只有一家就自动违反目标。应检查它的服务条件、是否被授予不可复制的独占资格，以及停止服务后形成替代所需的实际成本和时间。具体可接受范围需要预先约定。

开放新大陆也不能单独解决问题。如果旧集团总能提前包下全部新资源，新地区会再次复制原有控制结构。需要检查发现、申请、建设和运营几个环节的准入与控制，而不只统计地图面积。

## 5. 既要能用，也要能另起事业

后来者至少有两种不同需求：作为居民使用服务，以及作为创作者或经营者继续创造。

一家早期工坊可以对所有人开放销售，但如果它同时买断全部能源、新人建造许可和运输能力，后来者仍然只能购买，无法发展自己的项目。因此，低价消费不能单独证明进入机会公平。

建议对每类基础活动检查三条候选路径：使用公开提供的服务；转向其他真实可用的供应者；在可承担的条件下独立建立替代能力。这些路径不必对每个商品全部同时成立，但基础参与不能长期依赖一个居民或同一集团不可替代的许可。

“可承担”需要具体测量：材料、价格、等待、运输、操作和真实计算成本，以及可支配预算。只在理论上可行、实际要多年积累才能到达的路径，不能当作有效替代；也不能靠默认新人会付费、加入某公会或接受赞助来通过验证。

## 6. 从长期动态限制差距

单次公平入场不足以保证长期公平。需要检查以下循环是否会持续放大初始差距：更早的资本获得更多产能，产能收益再次购入排他资源，随后影响市场入口和公共规则。

候选方案可以组合使用：基础工具快速普及、经营规模的真实协调与维护成本、多源供给、普通空间扩展、关键特许权的条件与期限、对公共能力的持续投资。它们分别作用于不同环节，没有一种单独政策能保证全部目标。

不得只给每个账号设上限，就假定集团无法通过分身规避；也不能通过简单压低大企业效率，误伤真实分工、优质服务和有效规模。应按真实依赖、可得证据与行为效果分析，保留无法识别共同控制的情况。

建议分别观察新旧批次在相同目标下的有效能力差距，以及全体居民获得当代基础能力的时间。即使没有单一垄断者，差距持续扩大、后来者无法开展有意义项目，也可能违反 C16。

## 7. 公共供给与限制措施也有代价

- **不以持续上线保护资产。** 频繁税费、强制维护或“几天不上线就没收”可能把参与变成劳动义务。若引入稀缺经营权期限，应在授予时说明条件，并研究委托、暂停、退出与作品保存。
- **不靠清除合法历史维持公平。** 权利变更需要明确版本、影响范围和迁移方案；不因某人成功就后台扣减其余额。制度应尽早作用于排他权的授予与续期。
- **不把价格上限当作完整供给方案。** 限价可能伴随缺货、排队和转移收费，需要同时验证容量与实际交付。
- **不承诺无限免费福利。** 基础服务需要已有库存、产能和资金来源；应优先研究可实际交付的服务和工具使用机会，避免可反复领取、转售的无来源空投。
- **不强迫所有作品无条件开放。** 基础参与机会与私人创作权需要分别设计，可以提供公共替代，也可研究自愿许可、公开采购和合理期限。
- **不把公共运营者视为天然无害。** 若平台自己控制唯一入口、随意改价或撤销访问，同样可能破坏参与目标；也需要明确服务条件、可审计记录与恢复安排。

## 8. 如何验证：新人真实可用、可替代、可创造

本轮建议把以下压力场景加入 `EXP-0002` 的后续验证，暂不新增一套必须运行的大型实验。所有场景均未运行。

| 场景 | 测试动作 | 应观察的事实 |
|---|---|---|
| 关键工坊拒绝服务 | 早期主要供应者停止向后来者供给 | 新人能否找到真实替代，成本和中断时间是多少 |
| 多店同控制 | 同一主体通过多个身份经营表面独立设施 | 指标能否识别已知共同控制；无法识别时是否诚实报告 |
| 价格与通道变化 | 提高费用、封锁路线、占满预约容量 | 是否仍有可到达、可负担并能实际交付的路径 |
| 买断新区域 | 先行者尝试控制新增土地与基础供给 | 地图扩展是否真正增加了新人机会 |
| 技术与接口锁定 | 控制唯一配方、兼容接口或发布入口 | 后来者能否合法使用公共方案或建立独立替代 |
| 低价但不可创业 | 服务便宜，但独立设施全部准入被阻断 | 是否同时评估消费机会与创作、经营机会 |
| 长期积累与返回 | 多批身份加入、退出、返回，预算及规则保持可追溯 | 系统赋予的能力差距是否不断扩大；退出是否迫使劳动 |

候选指标包括：取得当代基础服务的时间与完整成本、独立完成一个有意义项目的门槛、真实可用替代路径、受单一控制主体影响的关键依赖，以及预算压力。定义相同服务质量和任务范围后再比较不同加入批次，不能把火箭与木屋直接当作同一需求比较。

市场份额、财富集中度、交易额可以作为补充观察，但不能单独判断垄断或公平。几个名称不同的供应者可能共同控制；一个暂时占大份额、但能够被替代的经营者，也不能仅凭份额就被认定必须惩罚。

对照条件、参与预算、公共支出、观察时长和可接受门槛应事先登记。测试必须让新人走完替代路径并取得结果，不能只由 LLM 判断“理论上存在替代”。具体数值没有在本轮确定，不采用临时补发资源掩盖制度失败。

## 9. 下一步待决

Q22—Q25 集中记录：哪些基础活动必须保持开放、适度先发优势用什么量衡量、哪些稀缺经营权允许附条件授予，以及怎样验证共同控制和集团封锁。

近期可以先选一项基础创作活动，把资源、知识、场地、设备和运输依赖画清楚，再对其中最容易被控制的一环做拒绝服务实验。目标是保护后来者实际参与与继续创造的能力，同时保留先行者的历史与适度回报。
