# ITER-0009：后来者看见当前世界

2026-10-26，Asia/Shanghai。采用本机原型：后来居民可以读取已有公共桥及建设者、实际可达地点与步行路线、本人物资和公共储备；直接使用前人建成的通路。完整回归 **138 项 HTTP、94 项真实 Chrome 通过**，本轮真实居民模型调用 **0**。

## 1. 来源与范围

用户要求拉取最新代码、继续开发并推送主分支。当前研发位置是此前已有的 Orca 工作树，本轮没有创建额外工作树。先保存前八轮已验收实现为 `c90ce91`，再合入远端 `e51c89f` 的文明发展和 `b8b5769` 的适度先发约束；合并提交为 `fcb2931`。README 和研发闭环文档的冲突已保留双方内容。

本轮按[冻结契约](../contracts/entry-guide-v1.md)完成只读入驻前置能力，由协调者直接实现，未启动新 worker。它不增加场景、schema、材料发行或世界动作，不实现共享工坊、自动化、动态身份注册或防垄断制度。零材料活动可继续并不等于后来者已取得充分的制造资源。

## 2. 已实现行为

- `observation.entryGuide` 在原只读事务中投影当前身份、位置、世界版本、已建桥、活动及路线。以实际墙和未铺桥水面计算最短路径；一段桥不会被误报成跨河通路。
- 路线列出实际经过的桥实体，保留建设者；显示公共储备与本人库存，不暴露同伴库存、不发材料。r1/r2 使用原目标，r3—r6 使用原活动目录。
- 浏览器在创作区前展示导览，选择地点只更新原地图／活动选项。详情展开状态和控件节点保留；断线显示上次观察并暂停导览操作，身份切换清空旧内容。旧服务没有导览字段时继续使用原界面。
- 新居民任务可获得同一个公开导览，字段白名单排除额外内容；原持久任务和旧服务保持兼容，不为加入导览重新决策。
- `npm test` 构建一次后运行全部普通套件；真实模型验收仍是独立显式入口。所有测试均使用隔离数据和服务，结束后关闭测试服务。

## 3. 实际后来者路径

[程序旅程](evidence/ITER-0009/program-late-entry.json)使用真实 HTTP：a1 花 6 木材建成 `(4,3)`、`(5,3)` 两段公共桥，世界版本达到 8。随后 a2 首次读取导览，从 `(1,2)` 沿 8 步路线到达 `(6,1)`，提交实际观景台到访，再返回原处。a2 没有领料或建造，原两段桥和建设记录保留；最终账本为公共木材 6、库存 0、实体材料 6，总量 12。

这段旅程由明确固定程序执行，Chrome 另以实际按钮完成同样的复用路径。新任务输入测试使用明确决策替身检查导览进入输入，不冒充真实模型决定。公共储备归零的另一案例验证了 a2 不能再领取木材，但仍能现场到访并写手记。
