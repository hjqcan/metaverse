# ITER-0010：从散落原始居民与实际采集开始

2026-10-26，Asia/Shanghai。已采用新的默认开局：居民分散、空手出生，没有预建建筑或可直接领取的公共木材。**木材先在树上，砍取后进入个人库存，再用于搭建和造桥。** 154 项 HTTP、105 项真实 Chrome 通过（完整运行加一套定向复验），本轮真实模型调用0。

## 1. 用户澄清与实现范围

用户明确“一开始是独立散落的野人，玩家要自己砍木头等采集资源进行发展”。C14 已由可能的题材改为确定初态。前九轮公共仓库领料原型作为历史实验保留，不再作为产品新世界的起点。

按[冻结契约](../contracts/wilderness-v1.md)增加 `wilderness-v1` / r7 / schema 7。未指定场景的新数据库默认采用它，`npm start` 使用 `.local/wilderness/` 和5088；已有数据库按保存的场景读取，不重置历史。历史 `run_world.sh` 显式选择原基础实验。本轮由协调者实现，没有新增工作树或 worker。

当前原型采用8×8地图，两居民在 `(1,1)` 与 `(6,6)` 分散出生。四处树木各含3木材，总量12；两岸各自有可采集来源，初始个人库存、公共库存与实体材料均为0。这些数量是本轮实验参数，未冒充用户指定的完整生态。

## 2. 已实现闭环

- 选择树木，走到上下左右相邻一格，执行一次 `gather` 砍取1木材。活树阻挡通行／建造，采空留下树桩，空地随之可用。
- 世界事务同时减少树木余量、增加本人库存、记录材料账、事件、版本与原命令回执。相同命令重试只确认一次；修改节点复用原ID被拒绝；争抢最后一份只会有一位取得。
- 自然材料账户 `wild-wood`、个人库存与建成实体独立核算，总量12。重启不会补满树木，也不重新散布已有居民；公共 `claim` 返回 `NO_PUBLIC_DEPOT`。
- 原平台／桥梁消耗真实采到的材料。自然地点是林间空地、河岸和对岸林地，没有预置花园画布、手记服务或观景设施。入驻导览按树木、岩壁、河流和已有桥计算路线。
- 人类与固定程序 Agent 使用同一采集接口。公开任务输入可读取自然来源；已有有界目标执行器暂不自动规划采集，缺料明确报需要自然采集，不假设存在仓库。没有进行真实模型采集验收。

[采集—造桥—复用记录](evidence/ITER-0010/program-gather-build-reuse.json)由固定程序通过真实 HTTP 完成：a1 先采6木材，再建两段桥；a2 从对岸初始位置走到 `(1,1)` 后返回 `(6,6)`，不采集、不建造、不消耗木材。最终自然木材6、库存0、实体材料6，总量12；原建设者与桥实体保持。

## 4. 初次失败与视觉修正

首次Chrome完成7项后，在错误回执测试中提前读取了尚在提交中的库存，得到1而非预期2；停服后的SQLite实际已经正确记录第二次采集，树木和库存守恒。测试改为等待故意修改的回执被处理和库存提交，再检查原命令仍未解决。没有修改产品事务来通过此测试。[初次结果](evidence/ITER-0010/browser-initial-results.json)保留。

完整 `npm test` 首次新增默认场景用例重复使用 `setUp` 已创建的数据目录，产生 `FileExistsError`；其余所有套件通过。给第二个隔离世界独立目录后，定向重跑全部16项采集HTTP通过。[原运行](evidence/ITER-0010/check-initial-results.json)、[原新HTTP结果](evidence/ITER-0010/http-wilderness-initial-results.json)和[标明替换来源的最终汇总](evidence/ITER-0010/check-results.json)同时保留，不把两次运行写成一次。

视觉复核发现自然地点的大标记遮住树木余量，原障碍也仍画成砖墙。新版将地点改为边角小编号和虚线范围，树木余量保持完整；岩壁改用不规则岩石。[修正前地图](evidence/ITER-0010/initial-map-before-visual-fix.png)保留，最终Chrome使用修正后的页面。

## 5. 运行与连续性

```bash
npm start
# http://127.0.0.1:5088
# .local/wilderness/access.json 中是本机两位居民的访问密钥

npm ci --prefix tests/browser --ignore-scripts
npm test
```

需要 .NET 10 SDK、Python3、Node.js和本机Chrome，`CHROME_PATH` 可指定浏览器。单套入口见[测试说明](../../tests/README.md)。默认产品入口已实际启动，认证只读核对：版本0、四处树木、自然木材12、两位分散居民库存0、没有建筑。没有把验收中砍过的树或建好的桥导入预览。

[健康记录](evidence/ITER-0010/preview-health.json)区分当前监听状态：5088新版正常；旧数据未迁移，也未为本轮自动启动未监听的历史端口。测试服务均已停止；新增的5088预览保留供用户查看。历史证据不修改，实际凭据与数据库只留在忽略目录。

## 6. 采用边界

本轮完成原始开局的采集建造闭环。没有实现饥饿、工具加工、部落制度、动态玩家注册、树木再生、长期自主演化或完整经济；四处有限树木也不证明先发差距和垄断问题已解决。后入者始终读取同一世界当前资源、地形与作品，不因个人首次连接重新开荒。

沿用用户要求，将完成的开发正常推送main并同步原主分支目录，不强制推送。该代码发布不等于公共网络部署。源码与证据哈希见[校验清单](evidence/ITER-0010/manifest.json)。
