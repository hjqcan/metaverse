# ITER-0013 · 原始世界 Agent 采集与造桥

2026-10-26。已实现并验证：有界居民任务可以从零库存出发，采集建桥所需木材，连通彼岸、到达后返回；后来者可以直接使用留下的桥。测试运行使用真实 HTTP／SQLite 和 Chrome，目标选择来自固定程序或显式测试替身，实际模型调用 0 次。

初始 12 木始终分布在自然来源、个人库存和实体中。采集与建造的数据库事件、原回执及材料账逐条核对一致；没有公共仓库发料，也没有资源再生。

## 改动

- 新任务可显式设置 `allowGather: true`。旧任务省略时维持不采集；原任务身份、spec、累计预算和起点不能在恢复时替换。
- 规划器先确认步行可达的来源足够，再补当前建桥缺口；不会把未连通对岸的木材当作现有供给。木材预算仍是建造实际消耗，每次采集和行走计入命令预算。
- 采集发送前保存节点和数量前提；回执按原命令、身份、节点、数量与版本核对。提交前后服务退出、居民进程退出、错回执均先恢复原命令，没有重复收获。
- 报告区分采集与领取；未知采集不计入收获，汇总与步骤不一致时不显示已核验完成。固定策略明确显示无模型调用和 token 消耗。
- CLI 新增 `--fixed-reference`，与 `--account` 互斥；新增建设者与后来者的任务样例，两个验收套件加入 `npm test`。

运行方式和精确边界见 [任务契约](../contracts/wilderness-resident-v1.md)，设计依据见 [提案](../proposals/ITER-0013-wilderness-resident.md)。
