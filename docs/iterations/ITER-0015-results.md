# ITER-0015：Agent 接入连续自然世界

2026-10-26。对应 [提案](../proposals/ITER-0015-continuous-resident.md) 与 [居民执行契约](../contracts/continuous-resident-v1.md)。本轮负责 Python Agent 与只读报告；r8 内核和 Godot 由另一会话实现。当前为可复核的本机候选结果。

## 已实现

居民使用米制小数坐标规划绕障路线，每次 `walk` 等待移动额度，以原命令回执确认实际位置。采集权限、完整材料缺额检查、桥梁位置选择、到达与返回、累计预算沿用持久任务机制。未知结果保留原 ID；错身份、错版本、伪造位置不结算；实际碰撞截停停止执行。旧 r1—r7 任务继续使用原坐标和预算约束。

报告支持自然河道、岩石、树木、实际桥面尺寸和连续轨迹，不取整到格子。地形是结束快照，位置按步骤回看。完成标记须与已提交位置及采集记录一致；未知行走不会把意图目标画成确认位置。固定策略明确展示模型调用和 token 消耗为 0。

## 实际旅程

同一个隔离 HTTP / SQLite 世界，先完成建设者任务，再让另一居民复用：

| 居民 | 命令 | 采集 | 建造消耗 | 新设施 | 到达与返回 |
|---|---:|---:|---:|---:|---|
| a1 建设者 | 94 | 6 木 | 6 木 | 1 座桥 | `[26.2,7.4]` 后返回 `[5,7]` |
| a2 后来者 | 80 | 0 | 0 | 0 | `[5.1,7.2]` 后返回 `[26,17]` |

桥中心 `[17.778125,11]`，前后实体 ID 一致。停服后检查外键、事件、回执、采集来源和资源账本，树木剩余、库存和设施材料总和仍为 12。目标由明确测试替身选择，**实际模型调用 0**，这不是模型能力或真人可玩性的验收。

公开样例：[建设者](evidence/ITER-0015/test-double-builder.json)、[后来者](evidence/ITER-0015/test-double-traveler.json)、[固定策略短途 CLI](evidence/ITER-0015/fixed-walk.json)。不含任务私有状态或 access 凭据。

## 使用与边界

`examples/continuous/` 提供同岸短途、采集建桥、后来者复用三个任务；命令见 [契约](../contracts/continuous-resident-v1.md#运行示例)。命令预算上限 1000、时间仍为 600 秒、到达容差 0.06 米。

这是有限候选的确定性导航，不承诺全局最短路径、任意地形完备性、动态人群避让或多桥网络。没有增加真实模型调用、持续自治、资源再生、完整经济或公开部署。Godot 的操作与画面验收另见 ITER-0014。
