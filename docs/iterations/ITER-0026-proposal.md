# ITER-0026 · 在原平台查看近期创作

2026-10-26。已采用[研究19](../research/2026-10-26-continuous/19-next-after-platform-canvas.md)并完成本轮实现与验收，见[结果](ITER-0026-results.md)。基线为`2948b68`及原平台revision2的两份实际创作。

本轮在Godot地画面板加入“近期创作”：按发生顺序选择已有修改，以5×5格直接展示原作者当次画的格子。其余格标为“本次未改”，明确不是当时完整图面；合法blank颜色与未改格区分。平台表面继续显示当前已确认图。返回当前作品保留同一身份内的原草图、基准和未决动作。

只使用通过现有`Canvas.supported`校验的观察及最近50条完整edit，不新发HTTP、世界命令或修改恢复文件。显示总次数与最近范围；选择绑定原实例／平台／作者／命令，新观察保留同一项，滑出窗口时清除选择并说明。连接代际、居民或实例改变时关闭并清除旧查看状态。观看不要求木材、署名、到场或允许发送业务动作。

协调者写`clients/godot/entity_canvas_panel.gd`和文档／测试入口；现有构建worker只写新增的针对性原生测试文件，独立QA只写隔离验收产物。后端、Python任务、Web报告及世界存储不变。

验收以实际Godot鼠标选择原5格／4格并返回9格为主，补充草图与pending保持、过期停止、blank区分、0／50以上记录、选择滑出窗口和身份切换。使用真实原观察与明确标记的合成界面夹具；不为只读表现另造绘制自然史。测试结束删除临时缓存，保留原自然头和必要证据。

这增加观看与理解既有作品的入口，不增加绘制容量，也不证明真人兴趣、长期留存或完整治理。C16—C17与Q05继续未决。
