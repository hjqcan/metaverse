# ITER-0026 · 查看原平台的近期创作

2026-10-26。已按[研究19](../research/2026-10-26-continuous/19-next-after-platform-canvas.md)和[本轮范围](ITER-0026-proposal.md)完成：原生客户端可以选择原平台的一次创作，辨认作者当次画的格子，再返回当前作品。作者定向测试8组155项、独立原生验收157项通过；实际模型调用0。

## 居民可以做什么

在“平台地画”中打开“近期创作”，按发生顺序选择作者的一次修改，直接看其当次画了哪些格子。灰色带点格表示本次没有修改；原patch中的空白色仍显示为一次绘制。查看的是这次修改，不能当作当时完整图面。

原平台已有两次实际创作：a1_alias留下5格河蓝，a2随后在4个空格接绘。新面板能分别展示它们，3D平台继续显示当前9格作品。观看不要求木材、本人署名或到场；它增加观看既有作品的入口，没有增加绘制空间或作品权限。

“当前作品”返回原编辑视图。同一连接和居民内，查看、切换记录和返回均保留原草图patch与基准；若期间图面更新，原草图继续显示过期，须明确新建。查看模式隐藏绘制操作，不发送业务信号，保留pending与last_receipt输入；查看代码没有恢复文件读写。

## 记录范围与原世界

界面只读取已经通过现有校验的`recentEdits`，最多最近50次，并显示总次数。选择绑定原实例、平台、作者和命令；新观察保留同一项，滑出窗口则明确取消，不能把同一下标的另一条记录当作原选择。切换连接、世界或居民时关闭查看并清除旧选择。更早记录仍保存在服务端，本入口没有新增分页或查询。

唯一产品源码变更是`clients/godot/entity_canvas_panel.gd`。世界服务、存储12、Python任务、Web报告、命令恢复和材料政策保持上一轮实现；本轮不增加HTTP请求或采用操作，也没有重新执行双人绘制旅程。

默认测试输入逐字取自ITER-0025原自然史的`stage-both/observation.json`，state1054、revision2，SHA-256为`575c2f6b9482621d3d74c82e80f2a1705c669fe754e69565228232d943fd4778`。它是保留的实际公开观察，界面夹具不携带令牌。原5格／4格与当前9格来自这条既有历史；0条、51条、blank、后续改色及身份切换等合成观察只用于界面边界，不计为新增自然活动。

## 验证

Godot 4.7.2导入通过。最初一处局部变量类型无法推断，改为明确String后修正；没有运行时世界变更。协调者已用原观察生成并目检当前作品、第一条及第二条三个预览；该预览通过函数选择，不冒充实际鼠标验收。

首轮测试脚本有原生类名称冲突，修正后，作者测试与独立QA都停在PopupMenu鼠标选择。初次[脚本解析失败](evidence/ITER-0026/worker-initial-parse-failure.json)、[作者输入失败](evidence/ITER-0026/worker-initial-input-failure.json)和[独立输入失败](evidence/ITER-0026/qa-initial-input-failure.json)已保留。独立QA修正局部／全局坐标路由后，同一产品源码通过157项断言，46次原生鼠标操作；没有用直接调用选择函数代替点击。

独立验收在原`stage-both`的小型隔离读取副本上，以非作者a3真实认证读取：库存3木、距平台约4.24米。启动1次GET后停用轮询，选择原5格、原4格并返回9格，选择过程0次请求、0 POST、0业务／移动信号。8张业务表逐项保持，原1034份回执、1055条事件、六实体和两条手记仍在；来源累计产出33及库存6保持，正常服务时间推进另记。原自然头及阶段文件字节未变。详见[独立结果](evidence/ITER-0026/qa-native-v1.json)、[鼠标驱动](evidence/ITER-0026/qa-ui-driver.gd)和[第一份](evidence/ITER-0026/qa-first-five.png)、[第二份](evidence/ITER-0026/qa-second-four.png)、[返回当前作品](evidence/ITER-0026/qa-current-nine.png)画面。

零库存、已有pending、后续blank改色、0／50／51／52条和身份变化使用明确标记的界面夹具；原草图的建立与切换使用实际鼠标。它们证明界面保留与隔离，不代表本轮执行了这些世界动作或恢复协议。完整源报告保留在本地；仓库归档保留原报告指纹、全部断言与输入记录，以逐项指纹替代重复的完整合成观察。

可复用测试已加入`npm run test:entity-canvas-history`及`test:godot`，直接使用仓库内公开观察，无服务、数据库或模型依赖。8组覆盖原两条创作、草图过期、非作者与pending、blank、最近窗口、身份变化、未知能力和原编辑信号。worker在测试取景调整前后均通过8组155项；[最终自检](evidence/ITER-0026/worker-native-v1.json)与[协调者npm入口复验](evidence/ITER-0026/coordinator-native-v1.json)使用同一最终测试源码，均8组155项通过，截图包含平台。运行分别记录，不累加成独立验收；[范围汇总](evidence/ITER-0026/coverage.json)保留各版本、初次失败与清理记录。

第二位测试agent只读核对源码、指纹、断言和三张原画面，[审核通过](evidence/ITER-0026/qa2-review.json)。这不是另一轮执行测试。实际HTTP观看者有3木；非空pending与身份切换为界面输入，未新增磁盘恢复或认证切换验收。独立驱动在首个真实观察后停用自动轮询，不能据此声称已验证实时轮询竞争或真人使用体验。

产品始终为冻结的[native-v1](evidence/ITER-0026/native-v1-manifest.json)，14个原生文件指纹逐项一致，只有地画面板不同于上一轮。本轮不为只读表现改动重跑后端整套或复制运行二进制。
