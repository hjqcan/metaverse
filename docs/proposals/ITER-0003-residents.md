# ITER-0003：目标选择、持久任务与可核查反馈

日期：2026-10-25。状态：已完成本机实现与验收，采用范围及证据见 [ITER-0003 报告](../iterations/ITER-0003-results.md)。

上轮证明公共桥梁改变可达性，但居民只执行写死的单一目标，而且完整任务与预算还没有持久记录。本轮让真实 GPT-6 依据目的选择目标，把执行过程、预算、恢复和事实反馈作为独立可观察对象。

选择一次模型决策加确定性执行，暂不采用每步自由生成动作：当前世界只有移动、领料、建造三类动作，逐步推理增加调用次数，却没有相应复杂玩法需要。也不把新增固定条件分支称为 LLM 自主决策。

冻结接口与验收条件见 [resident-mission-v1](../contracts/resident-mission-v1.md)。模型目标选择复用本机已绑定账号；外部构建仍使用 Orca 两账号 GPT-6 worker。本轮最多 4 次真实决策调用（包括接入探针），单任务 1 次、单次等待上限 180 秒；失败不自动换账号或提升预算。游戏命令每任务最多 100 条、木材最多 12、期限最多 600 秒。

分工：执行器 worker 仅写 Python 持久任务模块；视图 worker 仅写报告页面及入口；协调者负责 Codex 适配器、独立验收和真实运行。现有世界规则和 C# 内核不改，保留旧预览；不提交推送或公共发布。

官方依据：Codex [非交互模式](https://learn.chatgpt.com/docs/non-interactive-mode)支持结构化输出与 JSONL 事件；[配置参考](https://learn.chatgpt.com/docs/config-file/config-reference)说明命令执行工具开关和认证方式。具体参数仍以本机 CLI 0.164.0 支持和实际运行结果为准，不能只靠文档推定账号调用成功。
