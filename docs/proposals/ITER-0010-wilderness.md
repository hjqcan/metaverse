# ITER-0010：从散落原始居民开始

2026-10-26。状态：采用本机原型；结果见 [ITER-0010](../iterations/ITER-0010-results.md)。

用户进一步确定初始居民是独立散落的野人，发展资源需要自己砍树等采集。现有原型的相邻出生、公共仓库直接领料不符合这个开局。本轮按[冻结契约](../contracts/wilderness-v1.md)补齐分散空手出生、有限树木、采集到账与后续建造；既有世界持续保留，不让每个后来者重新开荒。

本轮不增加模型调用，不把“查看资源提示”当成已经采集；验收必须看到树木减少、原命令确认的个人库存增加与实际建成实体。相关早期资源、工具和生态参数仍需后续玩法实验。
