# ITER-0011 · Godot 3D 俯视客户端

2026-10-26，依据用户明确的“先用 Godot 做原型，后面迁移 Unreal”与“3D 俯视”。

本轮把既有原始开局接入实际引擎：低多边形地形、树木、分散居民、平台和桥段；鼠标选取与有限寻路、键盘移动、采集及建造。世界规则仍由现有 .NET / SQLite 服务维护，不改变 r7、数据库或资源发行。当前浏览器作为辅助入口保留。

需要证明：真实 Godot 输入能完成采集→库存→建造，另一居民看到同一成果；原命令在响应丢失、重启、版本冲突与身份切换后保持一致；树冠点击与俯视画面能使用。测试使用专用临时数据和端口，不在用户预览中砍树；不调用外部模型。

后续 Unreal 的迁移范围是客户端代码、画面和交互，不承诺引擎场景一键转换。当前不实现 Unreal 项目、连续物理移动、动画、工具系统、饥饿或部落。

操作与接口边界见[客户端说明](../../clients/godot/README.md)，结果见[验收记录](../iterations/ITER-0011-results.md)。
