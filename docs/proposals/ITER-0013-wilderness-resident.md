# ITER-0013 · 原始世界居民采集与造桥

2026-10-26，构建前提案。依据 C02、C06、C14—C17，以及用户“继续一直推进开发”。当前 `resident_mission.py` 遇到自然材料短缺只返回 `natural_material_collection_required`；人类已能砍树，Agent 有界任务尚不能完成相同建设闭环。

在既有任务中新增可选 `allowGather: true`，默认关闭，旧任务与持久状态不自动扩大权限。显式允许时，为当前目标所需桥梁补足材料：选择可步行到达的树旁、逐次采集、用实际库存造桥、到目标后返回原起点。采集只补当前缺口；木材预算仍限制建造消耗，采集与行走计入原命令和时间预算。模型仍只选一次高层目标，无新增模型能力、账号或常驻循环。

采集规划依据当前树木余量与通行事实，先确认可达材料足够，不把河对岸不可达的树计作可用供给。每条命令前重新观察；结果未知时保留原 ID、节点和提交前数量，先查询原结果，再决定后续行动。采集事实必须匹配原身份、命令、节点、数量与版本。报告区分领取与采集，旧报告兼容。

验收使用隔离真实 HTTP／SQLite 和真实 Chrome，模型调用预算 0。覆盖空手采集六木→两桥→往返，第二居民零采集复用，默认无采集权限、材料／命令预算、不可达或耗尽来源、采集提交前后进程退出、错误回执与原 ID 恢复、身份／任务绑定、旧任务回归。不会启动现有预览里的任务，也不修改 Godot 交互文件；资源再生、工具、部落和长期先发差距另行实验。
