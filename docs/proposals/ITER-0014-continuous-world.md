# ITER-0014 · 连续自然地图

2026-10-26。用户明确否定逐格行走和棋盘地图，要求正常地图、直接行走，并提供游戏开发技能库和3D游戏工作流参考。保持已确认的 Godot → Unreal 路线、3D俯视和原始居民采集开局。

实现范围：新增 `wilderness-continuous-v1` / r8 / schema8。服务端存实数米制坐标，校验移动速度并扫掠角色圆形占地；自然弯曲河道、树干和岩石阻挡行走。砍树、库存、平台、整座桥沿用现有命令身份、幂等回执和事务账本。Godot 替换棋盘、逐格寻路和侧栏，提供满屏场景、跟随镜头、直接点击交互、键盘自由行走与建筑占地预览。

[冻结接口](../contracts/continuous-world-v1.md) 供另一会话独立接入 Python Agent。本轮独占 C# 和 Godot，不修改其居民任务或报告查看器。旧 r1—r7 服务及数据保留；新预览单独使用 `.local/continuous` / 5089。

验收：实数位置与重启、斜向输入、点击目标、树干／岩石／河岸／边界截停、高频请求限速、同 ID 重放、采集建造事务、整桥双方复用、实际 OpenGL 场景拾取、断线和错误回执恢复。普通测试不调用模型。

采用的技能为 `godot-3d-essentials`、`godot-physics`、`camera-systems`。本轮没有独立3D资产生成服务、Unreal 实现、生态再生或工具制作，不把参考作品的最终画质作为已达到的结果。
