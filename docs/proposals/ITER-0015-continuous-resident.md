# ITER-0015 · Agent 连续坐标接入

2026-10-26。当前用户方向已转为正常地图与自由行走；世界内核和 Godot 由另一会话按 [连续世界契约](../contracts/continuous-world-v1.md) 实现，本轮只负责 Python 居民、任务报告和对应验收，不修改 C#／Godot 文件。

目标：Agent 在同一 r8 米制地形中规划连续路线，绕开树木、岩石和河道，经实际 walk 回执移动；采集够用木材，在河上建一座桥，到达目标再返回。后来者沿已有桥通行。原 r1—r7 任务作为历史规则继续运行，不把新地图压回格子。

规划使用公开几何、圆形角色间隙和可见路径连接，不把路径计算当作移动事实。每次 walk 等待服务端速度额度，保存原命令及起点；回执、未决恢复、身份、材料和预算保持原机制。连续任务允许有限实数目标，到达容差 0.06 米；命令预算上限 1000（旧场景仍 100），时间上限仍 600 秒，不增加模型调用。报告展示自然河道、连续位置、真实采集与建造，区分模型选择、固定策略和世界完成事实。

验收使用隔离真实 r8 HTTP／SQLite、真实 Chrome 和明确固定／测试策略，实际模型调用 0。覆盖分数坐标、无格子取整、绕障、限速、原 walk 丢响应恢复、异常回执、采集建桥往返、后来者复用、权限预算、旧任务与报告兼容。等待内核实现期间可以验证纯几何和报告输入，但不得据此声称真实连续世界已通过。
