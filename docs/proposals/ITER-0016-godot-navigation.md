# ITER-0016 · 点击行走绕障与过桥

2026-10-26。延续已确认的连续自然地图和 Godot 3D 俯视方向，补齐点击地面后只直走、碰到树石就停下的问题。居民点击可达位置后绕开树干、岩石与河道，经已建木桥到达另一岸；点击树冠走到采集范围，WASD 保留直接控制。

客户端使用 Godot NavigationServer3D，从 r8 观察中的真实几何异步烘焙导航网格；不以显示网格或逐格移动替代连续地图。只在树采空、桥建成或几何改变时更新，移动与库存变化复用原导航。路线只生成移动意图，每一步仍通过原 HTTP `walk`，由服务端决定速度、碰撞、位置与回执。

显示脚下路线和目的地；无法到达时明确提示，不向错误河岸自动替换目标。新点击、WASD、Esc、连接切换、应用失焦或不确定动作停止原路线。等候 HTTP 或导航更新的旧点击也必须失效。

写入边界为 `clients/godot/main.gd`、`world_view.gd`、新增 `world_navigation.gd`、专属测试与本迭代文档。Python 建造任务由 ITER-0017 会话负责；世界实例绑定、恢复记录存储和连接代际修复由主目录构建会话负责，合入时保留彼此改动。

验收使用隔离服务与真实 Godot/OpenGL 窗口：树石绕行、采空后路线更新、无桥不可达不发命令、真实材料建桥后双方通行、延迟请求期间的新点击和取消、丢回包后保留原命令且不自动继续旧路线，以及原采集建造与恢复回归。普通测试不调用模型。
