# ITER-0018 · 原命令恢复与世界实例

采用持久世界实例 ID 与 HTTP 前置条件，关闭同地址换新数据库后误恢复旧动作的反例；同时保留共享恢复记录与连接刷新修复。需求证据和备选边界见 [研究契约](../research/2026-10-26-continuous/03-instance-binding-contract.md)，实现协议见 [world-instance-v1](../contracts/world-instance-v1.md)。

范围为新建 r8 库的实例元数据、事务校验、Python 传输、Godot 逐命令持久记录和恢复 UI。Python 任务状态由 ITER-0017 对应写入者接入同一契约，整合后单独验收；导航由 ITER-0016 保持独立提交。

原命令 JSON、ID、语义哈希和历史 receipt JSON 不改写；同库重启、会话轮换与明确换地址可恢复。条件失败不能结清原世界未决。旧库不自动采用，旧记录不能从当前观察补造实例 ID。此轮不迁移预览、不处理克隆双写或备份回退，不增加经济参数。

可观察验收：新库独立身份；事务内拒绝缺失、重复与错误前置条件且业务表不变；同地址新库不执行旧动作；回到原世界或同库新地址按原 ID 结清；旧库升级保持事实与回执原文；旧格式及损坏保护记录保留；两 Godot 进程不覆写彼此未决；同居民同版本重连刷新场景并取消旧路线。任务验收另核对原起点、目标与累计预算。

所有验证用隔离数据库、随机本机端口、真实 HTTP/SQLite/Godot，模型调用 0。构建自测、独立测试和已有预览状态分别报告，不用源码或模型推演代替运行证据。
