# ITER-0021 · 居民身份与设施署名

2026-10-26。连续世界的原生客户端补全身份可见性：角色头顶显示居民 ID，当前控制者明确标作“你”；平台和桥显示观察中记录的建造者。切换居民后脚下标记必须随认证身份更新，不把模型、人类或离线居民推断为在线。

当前视图只在创建角色时选择圆环颜色，a1 切换 a2 后会保留旧角色的“自己”颜色。本轮修复这一问题，并在连接代际变化时清除旧场景、路线、角色插值和采集浮字，按新观察建立视觉基线。持续轮询仍平滑显示服务端确认的位置。

写入范围：`clients/godot/world_view.gd`、`main.gd` 的视图更新调用，以及本轮独立测试与文档。无服务端规则、资源、命令协议和恢复存储变更；设施署名不是所有权治理或访问限制。

验收用隔离真实 HTTP 世界和 Godot 渲染进程：合法采集建造；核对角色、设施署名及 a1/a2 实际认证切换；不同实例重连后不显示旧作品和旧浮字；同实例重连按当前坐标直接刷新；查看截图。测试结束停服并检查材料、作品作者和原回执。
